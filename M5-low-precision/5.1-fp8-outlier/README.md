# 5.1 · FP8 outlier

状态：已完成。实现位于 `quant_outlier.py`，包含 per-tensor E4M3
量化/反量化、逐点相对误差、1×128 per-block 对照和边界输入处理。

## 运行

从仓库根目录执行：

```bash
python -m pytest M5-low-precision/5.1-fp8-outlier/test_quant_outlier.py -q
python M5-low-precision/5.1-fp8-outlier/quant_outlier.py
```

本页数字由 `torch.manual_seed(0)` 的确定性 host 实验得到；本地复跑环境为
Python 3.12.7、PyTorch 2.7.1+cu118（CPU 路径）。

## 量化方法

令 E4M3FN 的最大有限值为 448。per-tensor 量化使用

```text
amax  = max_i |x_i|
scale = amax / 448
q_i   = cast_E4M3FN(x_i / scale)
y_i   = fp32(q_i) * scale
```

代码对空张量和全零张量作了显式处理，并拒绝 NaN/Inf，避免 `0/0` 或
无效 scale。实验张量包含 10,000 个 `U[-1, 1]` 元素和一个值为 3000
的 outlier，因此 outlier 只占 `1/10001 ≈ 0.010%`，却独自决定了
`scale = 3000/448 = 6.696428571`。

## per-tensor 实验结果

“实际 x”是随机张量中离题面采样点最近的元素；相对误差定义为
`|y-x|/|x|`。

| 目标采样点 | 实际 x | 反量化 y | 相对误差 |
|---:|---:|---:|---:|
| ≈0.5 | 0.500097632 | 0.523158491 | 4.611e-2 |
| ≈0.1 | 0.099997759 | 0.104631700 | 4.634e-2 |
| ≈0.01 | 0.009995580 | 0.013078962 | 3.085e-1 |
| ≈0.005 | 0.004943609 | 0 | 1.000e+0 |
| 3000 | 3000 | 3000 | 0 |

移除 outlier 后，`amax≈0.9998865`，scale 从 6.696428571 降到
0.002231890。相同 `x≈0.5` 采样点的相对误差降至 `3.086e-4`；本次
固定样本中，含 outlier 的误差是移除后的 **149.410 倍**。这个倍数依赖
采样点与 E4M3 格点的对齐，结论应理解为该固定实验结果，而非所有输入的
统一误差倍数。

## 量化为零的阈值

E4M3 的最小正 subnormal 是 `2^-9`。round-to-nearest 时，0 与该值的
中点为 `2^-10`，所以反量化为 0 的理论边界为

```text
|x| <= scale * 2^-10
```

含 outlier 时该边界为 `6.539481e-3`；实际随机样本中被量化为 0 的
最大 `|x|` 是 `6.482482e-3`，与理论边界一致。移除 outlier 后边界约
为 `2.180e-6`。outlier 并未改变 E4M3 的 3 个显式 mantissa bit，
而是通过把 scale 放大约 3000 倍，大幅抬高了原始数值域中的最小可表示
量级，首先损害小普通值的有效动态范围。

## 1×128 per-block 对照

10,001 个元素被分成 79 个 block；outlier 位于最后的 block 78，因此
其 scale 只影响 1 个 block，另外 78 个 block 不受污染。下表中的
“同组普通值”固定为最后一组除 outlier 外的 16 个元素，只改变这组是否
与 outlier 共用 scale。

| 对照 | scale | 零边界 | 普通值 MAE | 普通值最大绝对误差 | 零占比 |
|---|---:|---:|---:|---:|---:|
| clean block 0（128 元素） | 2.226625e-3 | 2.174438e-6 | 1.157410e-2 | 3.546017e-2 | 0% |
| 同组普通值，不含 outlier | 2.143758e-3 | 2.093513e-6 | 9.581371e-3 | 2.256727e-2 | 0% |
| 同组普通值，与 outlier 共组 | 6.696429 | 6.539481e-3 | 1.236691e-2 | 3.509289e-2 | 0% |

这 16 个固定普通样本恰好没有落入 `±6.539481e-3`，所以表中零占比仍为
0%；它不否定上面的零阈值。per-block 的关键收益是把 outlier 导致的高
零阈值限制在一个 128 元素范围内，而不是让全部 10,000 个普通元素共用
这个 scale。
