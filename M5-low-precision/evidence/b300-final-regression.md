| Registers / thread | 40 | 32 |
| Dynamic shared / block | 14.34 KiB | 0 |
| Achieved occupancy | 62.89% | 85.30% |

NCU replay 的 Duration 不用于正常计时表；表中加速比来自未插桩的 CUDA event
计时。融合 kernel 主要压在 L1/TEX 与片上数据通路，且因寄存器和动态 shared
memory 降低 occupancy；两步路径的独立 quant kernel 已接近同形 ceiling，故
省掉中间 BF16 流量不能直接兑现为理论 `6.56/2.56≈2.56x`。
