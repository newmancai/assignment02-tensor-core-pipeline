# 开源来源、改造边界与公开审计

## Multi-agent 来源

MARPE（迁移感知运行时配置演化框架）复用两项开源工作的成熟能力：

- **PIKE**：并行分支搜索、候选分配、错误修复分支和优胜分支选择；
- **Atrex Kernel Agent**：隔离 GPU 执行、profiling、Git episode、可恢复日志和 ABBA 交替验证。

准确上游地址、版本和许可证见 `third_party/UPSTREAM_LOCK.json`。本归档保留许可证与 NOTICE，没有把这两套系统声称为从零实现。

本文实现和讨论的新增部分是：HMMA/tcgen05 双分支 Program IR、带作用域的 Experience IR、公平预算协议，以及基于正确性、执行身份、计时完整性和统计证据的候选晋级。现有实验是窄宽度双分支闭环，未证明 multi-agent 相对单 agent 的性能优势。

## 公开内容

归档包含最终 PPT/PDF、论文源文件与 PDF、主线与历史报告、精选与完整机器可读证据、复现实验脚本、双层 IR/Agent 实现、CPU 测试、Slurm 作业、CUDA probe、关键补丁和上游许可证。

- 两个 `.pt` 张量快照，合计约 237 MB；它们是可重建的运行数据，不是源码或唯一证据。
- 编译产物、Python 缓存、完整 `.ncu-rep`/`.nsys-rep`、LaTeX 中间文件和第三方完整源码镜像。
- 迭代中的旧 PPT、渲染缓存和重复发布压缩包。

这些排除项不会改变表格中的测量值、Agent 决策记录或复现脚本。第三方源码按锁定版本从公开上游获取。
